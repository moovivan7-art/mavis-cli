# Универсальный фриланс-цикл

Это основной сценарий. Площадки различаются деталями — здесь логика, общая для всех.

## 0. Подготовка
- Убедись, что профиль (`profile.md`) заполнен. Без него отклики будут пустыми.
- Браузер: `browser open <url>`. Если просит логин/капчу — скажи об этом и попроси пользователя войти самому.

## 1. Сбор заказов
Ищи по своим ключевым словам и фильтрам (категория, бюджет от, «без ответов» / новые).
Не бери всё подряд: 5–15 свежих заказов достаточно за один заход.

Параллельные поиски по разным площадкам — делегируй подагентам (`delegate`), каждый получает свою площадку.

## 2. Фильтрация
Отсеивай по критериям из профиля:
- задача входит в мои навыки?
- бюджет выше моего минимума?
- сроки реальные?
- заказчик адекватный (по описанию)?
- не «сделайте за час то, что делают месяц»?

Оценка `fit` (0–100):
- 80–100 — откликаемся сразу
- 50–79 — отклик возможен, но подумать
- < 50 — не откликаемся, но заводим в пайплайн как `new` с пометкой

## 3. Заведение в пайплайн
Каждый осмотренный заказ — `jobs add` (platform, title, url, budget, fit, notes).
Это твоя память: через неделю ты не вспомнишь, куда откликался.

## 4. Отклик
- Напиши текст **под конкретный заказ**: упомяни суть задачи, свой релевантный опыт, цену и срок.
- Никакой «воды» и никаких шаблонных фраз. 2–5 предложений.
- Покажи текст пользователю до отправки.
- Отправка — только через `send_message` (спросит подтверждение).

## 5. После отправки
- `jobs update <id> {status: "replied"}` + заметка в историю.
- Жди ответа. Не пиши повторно в течение 24 часов.

## 6. Ответ и дальше
- Новое сообщение от клиента → прочитай, ответь по той же схеме (черновик → подтверждение → отправка).
- Клиент просит уточнить цену — ответь конкретно, без «обсудим» без чисел.
- Клиент пропал — один follow-up через 2–3 дня, потом в архив.

## 6.1 Переписка — не начинай с нуля
Перед каждым ответом клиенту — `threads get`: там, что ты уже писал, о чём договорились,
какие цены и сроки называл. Иначе легко ответить «по цене 5000» после того, как сам называл 3000.
После разговора — `threads append` (direction `out` для твоих сообщений, `in` — для клиента).
Диалог в терминале тоже переживает перезапуск, но переписка хранится отдельно и живёт дольше.

## Правила гигиены
- Один заказ — один осмысленный отклик. Никаких массовых рассылок.
- Не выдавай себя за другого человека, если в профиле нет твоих данных.
- Не обещай сроки, которые не сможешь выдержать.
- Сомневаешься в цене — спроси пользователя, а не ставь «рыночную».
