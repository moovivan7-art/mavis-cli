# Mavis — фриланс-агент в терминале

Ты в терминале, а перед тобой агент: он заходит на площадки, читает заказы, отбирает подходящие,
пишет отклики, ведёт переписку с клиентами и помнит весь контекст. Ты командуешь и подтверждаешь
исходящие сообщения.

```
mavis › найди на FL.ru заказы по вёрстке на Tilda, отбери 5 подходящих и покажи мне отклики
  ⚙ jobs            → заказ в пайплайне
  ⚙ browser         → лента заказов
  ⚙ send_message    → «Отправить в flru → Заказчик? [y/e/n]»
◆ Отклики готовы, 5 штук в /drafts. Отправляем?
```

## Что внутри

| Часть | Что делает |
|---|---|
| **Мозг** | MiniMax API (Anthropic-совместимый, рекомендуемый протокол) или любой OpenAI-совместимый |
| **Браузер** | Playwright + Chromium, **постоянный профиль** — логины живут между запусками |
| **Тулбелт** | `browser`, `bash`, `files`, `jobs`, `drafts`, `send_message`, `memory`, `todo`, `playbook`, `delegate` |
| **Пайплайн** | заказы и клиенты в локальном хранилище, не теряются между сессиями |
| **Переписка** | `threads` — история диалогов с каждым клиентом, чтобы не спрашивать повторно |
| **Диалог** | агент видит последние 6 сообщений разговора + краткий пересказ всей истории |
| **Гейт** | ни одно сообщение клиенту не уходит без твоего «y» |
| **Подагенты** | параллельные исследователи с чистым контекстом — не засоряют основной диалог |

## Установка

```bash
cd mavis-cli
./install.sh          # node 20+, playwright, chromium, symlink в PATH
```

Или вручную:

```bash
npm i -g ./mavis-cli
npx playwright install chromium
```

## Первый запуск

1. **Войди в площадки.** Агент работает через профиль `~/.mavis-cli/browser-profile`.
   Чтобы залогиниться вместе с ним — запусти `mavis --headed`, открой нужные сайты и войди руками.
   Капчу и СМС-подтверждения агент не обходит — и не должен.

2. **Заполни профиль** `~/.mavis-cli/profile.md`: навыки, ставки, портфолио, как ты пишешь клиентам.
   Без этого отклики будут пустыми иgeneric — агент не будет выдумывать твой опыт.

3. **Дай API-ключ MiniMax** — спросит при первом запуске, сохранит в `~/.mavis-cli/config.json` (права 600).
   Ключ: https://platform.minimax.io → API Keys.
   Подойдёт и любой OpenAI-совместимый ключ: `mavis --protocol openai --base-url https://... --model ...`

## Использование

```bash
mavis                              # интерактивный режим
mavis --headed                     # с видимым браузером (для логинов)
mavis --task "найди заказы по копирайтингу"   # разовый заход (для cron)
mavis --offline --task "привет"    # без сети, для проверки установки
mavis --context 10                 # видеть 10 последних сообщений вместо 6
mavis --new                        # начать диалог с чистого листа
mavis --update                     # обновить самого себя (тянет свежий код с GitHub)
mavis --check                      # самодиагностика: всё ли живо
```

**`mavis --check` — одна команда вместо гадания.** Проверяет и печатает вердикт по каждому пункту:

```
✔ Конфиг: API-ключ            eyJhbG…3456 · права 600
✔ Окно: предыдущие реплики + пересказ в запросе
✔ Тулбелты                   11 шт: browser bash files jobs drafts threads send_message …
✔ Браузер: Playwright + папка профиля
✔ Профиль пользователя        412 символов · ~/.mavis-cli/profile.md
✔ Плейбуки                    5 шт: flru.md freelance-flow.md kwork.md telegram-web.md upwork.md
✔ Сессия: сохраняется и поднимается
✔ Пайплайн и память            заказов: 4 · черновиков ждут: 1 · заметок: 7
✔ API: модель отвечает        MiniMax-M3.1-Flash · 812 мс · «ок»
✔ Контекст: модель помнит предыдущую реплику
    «Тебя зовут Проверка контекста, ты делаешь лендинги на Tilda.»
```

Последний пункт — живая проверка главной фичи: агент сам спрашивает у модели «как меня зовут» и
смотрит, помнит ли она предыдущую реплику. Если красный — значит контекст не работает.
Красные пункты сразу содержат подсказку, что чинить. Быстрая версия без запросов к модели:
`mavis --check --check-fast`.

**Обновление — одна команда.** `mavis --update` сам находит свою папку, скачивает свежий код,
делает бэкап в `~/.mavis-cli/backups/` и раскладывает поверх. Если установка — git-клон, работает
через `git pull`. Первичная установка/обновление одной командой:

```bash
curl -fsSL https://github.com/moovivan7-art/mavis-cli/archive/refs/heads/main.tar.gz \
  | tar xz -C /tmp && bash /tmp/mavis-cli-main/mavis-update.sh
```

Разовый заход — тоже часть диалога: `--task` поднимает сохранённый контекст сессии
(`main` по умолчанию, `--session <имя>` — своя ветка) и сохраняет его обратно. Без этого
каждый заход отвечал бы вслепую. Начать с нуля — `--new`.

### Команды в диалоге

| Команда | Что делает |
|---|---|
| `/context` | что агент видит прямо сейчас: последние сообщения + пересказ диалога |
| `/jobs` | список заказов в пайплайне |
| `/job <id>` | карточка заказа с историей |
| `/threads` | переписки с клиентами и счётчики непрочитанного |
| `/drafts` | черновики, ждущие отправки |
| `/approve <id\|all>` | показать тексты для отправки вручную |
| `/deny <id>` | отклонить черновик |
| `/session [save\|load <name>\|list]` | работа с сохранёнными диалогами |
| `/browser <url>` | открыть страницу |
| `/snapshot` | снимок текущей страницы |
| `/playbooks` | список гайдов по площадкам |
| `/profile` | показать профиль |
| `/stats` | сводка по пайплайну |
| `/clear` | очистить контекст диалога |
| `!команда` | выполнить команду в терминале напрямую |

## Как это устроено

**Браузер.** Агент смотрит страницу не глазами, а через компактный снимок DOM с номерами элементов:

```
URL: https://www.fl.ru/orders/
## ЭЛЕМЕНТЫ
[12] link — "Сверстать лендинг на Tilda"
[13] input[text] — "Поиск по заказам"
## ТЕКСТ СТРАНИЦЫ
...
```

и действует по номерам: `click(12)`, `fill(13, "лендинг")`. Номера протухают при перерисовке —
агент это знает и переснимает страницу.

**Гейт подтверждения.** Любой исходящий текст сначала попадает в черновик, потом агент показывает его
тебе: `[y]` отправить, `[e]` отредактировать и отправить, `[n]` отклонить. Если сломалось — сообщение
не уходит, а остаётся в черновиках, и агент честно об этом говорит. Никогда не «отправлено успешно»,
если текст не дошёл.

**Пайплайн.** Каждый осмотренный заказ заводится в `jobs` с оценкой подходятельности, бюджетом и ссылкой.
Через неделю ты не вспомнишь, куда откличался — агент вспомнит.

**Переписка.** `threads` держит историю диалогов с каждым клиентом. Перед ответом агент читает
`threads get` — что уже обсуждали, какие цены называл, — и не повторяется. После разговора пишет
`threads append`. Плюс рутина «что нового»: скан списка диалогов → `threads ingest` → агент видит
непрочитанные и знает, кому писать.

**Диалог переживает перезапуск.** Контекст разговора сохраняется в `~/.mavis-cli/state/` и поднимается
при следующем `mavis`. Начать с чистого листа — `mavis --new`. Отдельные ветки — `--session <имя>`.

**Что агент реально видит.** Два слоя:

- *Последние 6 сообщений* (реплики + ответы агента) уходят в модель дословно — по умолчанию 6,
  меняется через `agent.contextMessages` или флагом `--context N`. Считаются именно реплики, а не
  служебные сообщения: два десятка вызовов инструментов больше не выедают исходную задачу из контекста.
- *Пересказ диалога* — по строке на раунд («Ты: …» / «Mavis: …») — уходит в системный промпт. Он
  помнит всё, что было раньше, даже если ранние реплики уже выпали из окна. Поэтому на «а теперь?»,
  «и второй заказ тоже» агент не переспрашивает, а продолжает с того места, где остановились.

Посмотреть оба слоя можно командой `/context`. Сколько реплик держать в окне — твой выбор:
`--context 12`, если работаешь дольше и хочешь больше «памяти».

**Подагенты.** `delegate` запускает отдельного агента с чистым контекстом: пока он ищет заказы на Kwork,
ты общаешься с клиентом в Telegram, и диалоги не смешиваются.

**Гайды.** Перед работой с площадкой агент читает гайд: `~/.mavis-cli/playbooks/`
— `freelance-flow`, `flru`, `kwork`, `telegram-web`, `upwork`. Свои гайды добавляй туда же.

## Правила, которые зашиты в агента

- Никаких массовых рассылок. Один заказ — один осмысленный отклик под конкретную задачу.
- Никаких выдуманных фактов: цены, сроки, опыт — только из `profile.md` и памяти. Нет данных — спросит тебя.
- Никаких откликов по 20 заказов в день — площадки режут аккаунты за спам.
- Если капча, логин слетел или кнопка не находится — агент говорит об этом и просит тебя, а не
  выдумывает, что всё отправил.
- Письма клиентам — коротко, по делу, от первого лица, без «я ИИ-агент».

## Конфиг

`~/.mavis-cli/config.json`:

```jsonc
{
  "provider": {
    "protocol": "anthropic",          // anthropic | openai
    "baseUrl": "https://api.minimax.io/anthropic",
    "model": "MiniMax-M3.1-Flash",
    "maxTokens": 8192,
    "effort": "medium"                // low | medium | high | max
  },
  "agent": {
    "maxSteps": 30,
    "workspace": "~/.mavis-cli/workspace",
    "approvalMode": "ask",            // ask | auto | deny
    "contextMessages": 6,             // сколько последних реплик агент обязан видеть
    "historyLimit": 60,               // потолок на сырые сообщения (реплики + tool-обвязка)
    "recapLimit": 24                  // сколько раундов хранить в пересказе диалога
  },
  "browser": {
    "profileDir": "~/.mavis-cli/browser-profile",
    "headless": true,
    "executablePath": null            // если Playwright не нашёл Chromium
  }
}
```

Флаги: `--model`, `--base-url`, `--protocol`, `--key`, `--headed`, `--offline`,
`--approval ask|auto|deny`, `--workspace`, `--max-steps`, `--context N`, `--session <name>`, `--new`.

## Проверка установки

```bash
node test/smoke.mjs
```

Тест поднимает локальный сервер, который говорит на протоколе Anthropic, прогоняет через него
агента (формат запроса, tool-call цикл, thinking-блоки, гейт подтверждения, пайплайн), затем
открывает реальный Chromium, заполняет форму, отправляет сообщение и проверяет, что черновик
помечен `sent`, а заказ — `replied`.

Отдельно проверяется контекст диалога: окно держит последние 6 реплик, вызовы инструментов не
вытесняют исходную задачу, пересказ переживает обрезку и попадает в запрос, битая сессия
(обрыв посреди вызова инструмента) не ломает диалог, а `/context` показывает, что агент видит.

## Границы

- Агент не обходит капчи, 2FA и СМС-подтверждения — логинишься ты.
- Автоматизированы каналы `telegram`, `flru`, `kwork`. Для остального (`upwork`, почта) агент готовит
  текст, а ты отправляешь.
- Вёрстка площадок меняется — поэтому гайды и адаптеры живут в текстовых файлах, а не в коде.
  Сломалось — правится за минуту.
- Площадочные правила и лимиты — твоя ответственность. Агент старается не выходить за них, но
  не знает всех региональных нюансов.
