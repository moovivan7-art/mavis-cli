# Как подключить протокол на своём компьютере

Протокол уже в репозитории (`templates/protocol.md`) и подключается как файл.
Агент читает `~/.mavis-cli/protocol.md` при каждом запуске — можно править под себя.

## Три команды

```bash
# 1. обновить агента (подтянет новый код из GitHub, сделает бэкап)
mavis --update

# 2. убедиться, что протокол на месте (при первом обновлении ставится сам)
ls -l ~/.mavis-cli/protocol.md

# 3. проверить, что всё живо
mavis --check
```

Если `mavis --update` не сработал — одной строкой с GitHub:

```bash
curl -fsSL https://github.com/moovivan7-art/mavis-cli/archive/refs/heads/main.tar.gz \
  | tar xz -C /tmp && bash /tmp/mavis-cli-main/mavis-update.sh
```

## Если протокол не появился

```bash
cp /tmp/mavis-cli-main/templates/protocol.md ~/.mavis-cli/protocol.md
```

## Что ещё нужно сделать руками

| Что | Зачем | Как |
|---|---|---|
| **Заполнить `~/.mavis-cli/profile.md`** | Навыки, стек, опыт, портфолио, минимальная ставка. Без этого отклики будут пустыми, а агент начнёт выдумывать. | Открой файл и заполни |
| **Починить браузер** | `browser` ищет Chrome по `/opt/google/chrome/chrome`. Если Chrome нет — агент не сможет открыть ни одну площадку. | `npx playwright install chromium` |
| **Войти в площадки** | Чтобы агент работал под твоими логинами, профиль браузера должен быть авторизован. | `mavis --headed` → войди в FL.ru / Kwork / Telegram Web |
| **Выбрать канал управления** | Куда стучаться за карточками `J-001` и куда писать отчёты. | Почта или Telegram |

## Как проверить, что протокол реально работает

```bash
mavis --task "найди заказ на 1–2 дня по профилю из profile.md и пришли карточку J-001"
```

Агент обязан:
- найти заказы на FL.ru/Kwork,
- **не написать никому** без твоего «БЕРЁМ J-001»,
- прислать карточку по формату из протокола.

Если он отправил отклик сам — значит `approvalMode` сбит с `ask`. Проверь `~/.mavis-cli/config.json`:

```json
"agent": { "approvalMode": "ask" }
```

`auto` там быть не должно — по протоколу молчание и отсутствие ответа согласием не считаются.

## Что из протокола ещё не сделано в коде

Пока это только правила для агента. Механика, которую нужно дописать:

- формат карточки `J-001` как отдельный отчёт с оценкой расхода и ресурсов;
- состояния заказа (Найден → Оплачен и закрыт) в реестре;
- команды `СТАТУС`, `БЕРЁМ J-001`, `ОТКЛИК`, `ПРОПУСТИТЬ`, `ПАУЗА`, `ПРОДОЛЖАЙ`, `СТОП`;
- скоринг по сроку 1–2 дня, активному времени и чистой оплате;
- проверка заказчика: дата публикации, история, комиссии вывода;
- батч-режим: пачка карточек, ты отвечаешь «БЕРЁМ J-002, J-003» — агент доводит до сдачи.
